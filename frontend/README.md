# Front-end

Interface React + TypeScript do Controle de Gastos.

## Comandos

```bash
npm ci
npm run dev
npm run lint
npm run build
```

Por padrão, a aplicação chama a API em `http://localhost:5175`. Para usar outro endereço, copie `.env.example` para `.env.local` e ajuste `VITE_API_BASE_URL`.

Consulte o [README da raiz](../README.md) para instruções completas do projeto.
