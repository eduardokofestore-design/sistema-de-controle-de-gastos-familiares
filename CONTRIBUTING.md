# Como contribuir

1. Abra uma issue para discutir mudanças relevantes antes de implementá-las.
2. Crie uma branch descritiva a partir da `main`.
3. Mantenha as mudanças focadas e atualize a documentação quando necessário.
4. Execute os testes, o build e o lint descritos no README.
5. Abra um pull request preenchendo o template e descrevendo como validou a alteração.

Ao contribuir, você concorda em seguir o [Código de Conduta](CODE_OF_CONDUCT.md).
